## Design Notes

The designs focus on consistent typography, colours, spacing and visual hierarchy across the authentication and team pages.

The final designs incorporate team feedback, including:
- Removal of Google sign-in from the Sign In page
- Consistent account navigation links
- Colour-coded team role tags
- Corrected team member information
- Invalid email error state
- Long team-member blurb handling
